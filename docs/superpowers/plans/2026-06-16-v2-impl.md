# Crypto Price Bot v2 — 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将单文件 Node/Bun crypto-price-bot 重构为 Node 22 + Vite/React + SQLite + 多阶段 Docker 的完整可配置 Web 应用。

**架构：** 单进程 Node 22 LTS 服务，内置 HTTP 路由 + cron 调度 + SQLite 持久化；前端 Vite + React + Ant Design SPA 由后端同进程提供静态文件。

**技术栈：** Node 22 LTS · TypeScript 5 · better-sqlite3 · zod · bcryptjs · node-fetch (内置) · vitest · Vite 5 · React 18 · Ant Design 5 · @dnd-kit

**参考：** 设计文档 `docs/superpowers/specs/2026-06-16-crypto-price-bot-v2-design.md`
